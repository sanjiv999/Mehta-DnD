# Inbox: drop pictures here

Upload any picture you have made into this folder (on GitHub: **Add file → Upload files**; it
works from a phone). Name it with the number from `PICTURES.md` (`07.png`) or the slot name
(`ch01-s3.png`, `npc-badal.png`, `portrait-aarya.png`). GitHub files it into the right place,
rebuilds the website and crosses it off the list. Pictures it cannot place stay here, and Claude
sorts them when you say which is which.
