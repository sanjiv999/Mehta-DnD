# Prompt: generate an NPC

---
Read CLAUDE.md. Roll `python tools/roll.py --table names-<setting>` for a name. Create
`campaigns/<id>/npcs/<slug>.md` from the template with: looks (three concrete details), a voice note,
one want, one offer, and a secret that connects to an open thread in state.yaml. Make them
someone a five-year-old would remember: one funny thing, one kind thing.
